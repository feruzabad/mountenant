# 7. SQLite storage conventions

Date: 2026-10-07

## Status

Accepted

## Context

Specification §9 fixes SQLite (`modernc.org/sqlite`, WAL, one writer and a
read pool) and forward-only migrations, but leaves some choices open: "Times
stored as UTC RFC 3339 text or Unix milliseconds (pick one, consistently)",
how status values are spelled, and how strictly SQLite should type columns.
Every repository adapter and every migration depends on these, so they are
fixed before the first table is written.

## Decision

1. **Times are Unix milliseconds** in `INTEGER` columns, always UTC. Integers
   compare and index cheaply, cannot carry a time zone by mistake, and match
   the millisecond timestamp in UUIDv7 IDs. Conversion happens only in
   repository adapters (`time.UnixMilli` / `Time.UnixMilli`). Calendar days
   for quotas (`usage_daily.day`) are `YYYY-MM-DD` text in UTC, because they
   are keys, not instants.
2. **Status values are lowercase text** (`queued`, `importing`, `ready`,
   `failed`, `deleted`) guarded by a `CHECK` constraint; the domain maps them
   to its own type.
3. **Tables are `STRICT`**, so a wrong Go type fails on insert instead of being
   silently coerced. Pure key tables are also `WITHOUT ROWID`.
4. **Invariants that are cheap to state in SQL are also enforced there**: one
   live job per owner and digest (partial unique index), `failure_code` set if
   and only if the job failed, `expires_at` set for every non-deleted job, and
   foreign keys with `ON DELETE CASCADE` for job files and NZB blobs. The
   domain stays the primary guard; the schema is the backstop.
5. **`job_events.id` is `AUTOINCREMENT`**, so event IDs are never reused after
   pruning and a stale `Last-Event-ID` is always recognised (UC-30).
6. **Migrations run through goose's provider API** from an embedded FS, one
   transaction per file; the `Down` section of every migration fails on
   purpose, since releases never roll back.
7. **IDs are canonical lowercase UUIDv7 text**, generated by
   `internal/platform/id`.

## Consequences

- Raw SQL in `sqlite3` shows numbers instead of readable times; operators use
  `datetime(col / 1000, 'unixepoch')`.
- The `CHECK` constraints and partial index must change together with the
  domain state machine, in a new migration.
- STRICT tables need SQLite 3.37 or newer, which the pinned driver provides.
